# Story Generator（故事生成器）

[English (README)](./README.md)

一个基于 Vue 3 + Electron 的桌面优先、多 Agent 协作故事创作工作台。

该项目用于把“故事配置 -> 大纲 -> 章节规划 -> 写作 -> 校对 -> 润色”串成完整流程，并通过 AI 辅助提升产出效率。

## 功能简介

- 面向项目的故事创作流程
- 故事规划（主线大纲 + 角色管理）
- 章节规划与章节写作工作区
- 右侧 AI 侧边栏（`Vibe AI`）工具化编辑
- 可选阶段：会议/校对/润色
- 本地持久化（项目数据与会话历史）

## 技术栈

- Vue 3 + Vite
- TypeScript + Pinia
- Electron + electron-builder

## 快速启动

1. 安装依赖

```bash
pnpm install
```

2. 启动开发环境

```bash
pnpm dev
```

3. 构建前端资源

```bash
pnpm build
```

4. 构建桌面包

```bash
pnpm electron:build
```

## WalkThrough（5-10 分钟）

1. 新建或打开一个项目。
2. 在**故事配置**中填写：
   - 主题 / 类型 / 主语言
   - 章节数与约束（必须元素 / 禁止元素）
3. 进入**故事规划**：
   - 手动或 AI 生成**主线大纲**（整个故事的全局弧线）
   - 创建或调整角色
4. 进入**章节规划**：
   - 为每章完善：标题、目标、冲突、关键事件、角色行动、信息揭示、结尾钩子
5. 使用右侧 **Vibe AI**：
   - 发起定向修改（大纲字段、章节文本、风格优化）
   - 查看工具执行结果并应用
6. 进入**写作**，并按需执行**校对 / 润色**。
7. 保存后重启应用，确认数据持久化正常。

## 说明

- 当前仓库没有单独的 `typecheck` npm 脚本，可使用：

```bash
npx vue-tsc --noEmit
```

- 如果构建时遇到 `spawn EPERM`，通常是环境权限问题，建议提升权限后重试。
